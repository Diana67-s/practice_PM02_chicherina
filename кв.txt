1.	Какие профессиональные компетенции формируются в рамках ПМ.02?
Ответ: В рамках ПМ.02 формируются профессиональные компетенции, связанные с разработкой программных приложений, в частности умение проектировать пользовательские интерфейсы, работать с базами данных, программировать на выбранных языках, а также навыки системного анализа и тестирования программных продуктов.
2.	Почему выбран стек: Python + MySQL + tkinter? Какие альтернативы можно было рассмотреть?
Ответ: Этот стек выбран за простоту, доступность и широкие возможности. Python — язык высокого уровня, простой в освоении, с богатым набором библиотек. MySQL — популярная реляционная база данных, хорошо интегрирующаяся с Python. Tkinter — стандартная библиотека для создания графических интерфейсов на Python. В качестве альтернативы можно использовать:
Языки: Java, C#, JavaScript 
Базы данных: PostgreSQL, SQLite, MongoDB (для NoSQL) 
Фреймворки для создания графического интерфейса: PyQt, Kivy, wxPython
3.	Что такое ER-диаграмма? Для чего она нужна?
Ответ: ER-диаграмма (диаграмма «сущность-связь») — это графическое представление структуры базы данных, показывающее сущности (таблицы), их атрибуты и связи между ними. Она нужна для проектирования базы данных, чтобы наглядно определить структуру и взаимосвязи данных.

4.	Какие типы связей между таблицами существуют? Приведите примеры из своего варианта.
Ответ: Основные типы связей:
Один к одному (1:1) — например, у каждой организации есть один учредительный документ. 
Один ко многим (1:N) — например, у одного клиента может быть много заказов. 
Многие ко многим (M:N) — например, студент может записаться на несколько курсов, а каждый курс — на несколько студентов.

(Пример зависит от вашего варианта базы данных, укажите конкретные связи из вашего проекта.)

5.	Что такое Git? Чем отличается git commit от git push?
Ответ:
Git — система контроля версий, позволяющая отслеживать изменения в коде и работать в команде.  
git commit — сохраняет текущие изменения в локальном репозитории, создавая «снимок» состояния проекта.  
git push — отправляет сделанные коммиты на удалённый сервер (например, GitHub), делая их доступными для других участников команды.
